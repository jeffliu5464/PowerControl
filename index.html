PowerControl

A lightweight power management utility for Ubuntu Linux, designed to make common AC, battery, display, suspend and hibernate settings easier to manage.

Download PowerControl View on GitHub
Current desktop build: PowerControl 1.0.4 · Ubuntu Linux · amd64

Features

  • Configure AC idle timeout and action
  • Configure battery idle timeout and action
  • Set screen blank timeout
  • Manage system power profiles
  • View suspend memory mode
  • Check hibernate capability
  • Suspend or hibernate the system directly

Installation

Download the latest Ubuntu package from the GitHub Releases page. For a downloaded Debian package, installation can typically be done with:

sudo apt install ./power-control_1.0.4_amd64.deb

A Snap / Ubuntu App Center edition is also planned.

Platform

PowerControl is developed for Ubuntu Linux on amd64 systems. The application focuses on common desktop power-management settings while keeping system-level operations explicit and user-controlled.

Privacy

PowerControl does not require personal account information for its core power-management features. The free edition may display advertising supplied by third-party advertising services when online.
